
## AURA-IQ 
is an AI-powered energy management solution designed to help commercial buildings optimise energy consumption while maintaining occupant comfort.

- predicts building occupancy using existing data sources such as Wi-Fi access point distribution and calendar booking systems
- divides buildings into micro-zones and uses occupancy information to dynamically control HVAC and lighting systems, allowing energy consumption to be optimised based on actual occupancy.

## Key Features
Occupancy Prediction — Estimates the number of occupants using existing building data.
Micro-Zone Energy Management — Uses Wi-Fi access point distribution to create micro-zones for more targeted energy control.
Dynamic HVAC & Lighting Control — Adjusts energy consumption according to predicted occupancy.
Occupant Feedback — Allows occupants to provide feedback on temperature and lighting conditions, enabling the system to balance energy efficiency with user comfort.
Privacy-Conscious Design — Uses anonymised metadata for energy management purposes.
